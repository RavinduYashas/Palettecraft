# Palettecraft

Palettecraft is a free, user-friendly web design tool that helps designers and developers find perfect color palettes and font combinations for their websites. No sign-up required – just open and start creating!

## 🌟 Features

### 🎨 Color Palette Generator
- Generate beautiful color schemes with our smart tool
- Browse over 1,200+ curated color palettes
- Export CSS code for easy implementation in your projects
- Preview palettes in real-time

### 🔤 Font Pairing Tool
- Explore 500+ font combinations
- Preview how fonts look together
- Get implementation code for your web projects
- Perfect typography harmony for modern websites

### 📚 Resources & Tools
- **Contrast Checker**: Ensure accessibility compliance
- **Color Picker**: Select colors from images or manually
- **Color Theory Guide**: Learn the fundamentals of color design
- **Typography Guide**: Master font selection and pairing
- **Web Design Tips**: Best practices for stunning websites
- **Video Tutorials**: Step-by-step guides for beginners

### 🌙 Additional Features
- Dark/Light theme toggle for comfortable viewing
- Responsive design works on all devices
- Mobile-friendly interface
- Fast and lightweight – no heavy frameworks

## 🚀 How to Use

1. **Color Tool**: Visit the [Color Palettes](colors.html) page to generate or browse color schemes
2. **Font Tool**: Go to [Font Styles](fonts.html) to find perfect font pairings
3. **Resources**: Check out [Resources](resources.html) for tools and educational content

Simply click on any tool to start using it immediately!

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for structure
- **CSS3**: Custom styling with Tailwind CSS framework
- **JavaScript**: Interactive functionality
- **Font Awesome**: Icons for better UI
- **Google Fonts**: High-quality web fonts

## 📱 Local Development

This is a static website with no build process required. To run locally:

1. Clone or download the repository
2. Open `index.html` in your web browser
3. Navigate through the different pages
